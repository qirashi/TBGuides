# 📕 Инструкция по конвертации DVPL

## Что такое DVPL?

**DVPL** или **Dava Packed/LZ4** — это формат архивов, используемый разработчиками для хранения игровых ресурсов. Основная его задача, это сжатие данных.  
Из-за того, что файлы сжаты в `.dvpl` их модификация затруднена. Файлы требуют предварительной распаковки и сжатия после их модификации.

## Программы для работы с DVPL

Программа [**dvpl_go**](https://github.com/qirashi/dvpl_go/releases) позволяет работать с файлами в формате DVPL, а именно распаковывать или сжимать.
